# Universal Calculator

Native, offline-first Android mathematics workspace.

## Included foundation
- Standard/scientific expression evaluation with precedence and functions
- DEG/RAD/GRAD angle modes
- Complex arithmetic
- Factorials, combinations, permutations, GCD/LCM
- Matrices: multiplication, transpose, determinant, inverse
- Descriptive statistics
- Unit conversion foundation
- History/memory UI
- Graphing and tools surfaces ready for expansion
- Dependency-light mathematical engine and automated tests
